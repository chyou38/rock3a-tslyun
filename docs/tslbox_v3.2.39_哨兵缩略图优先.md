# tslbox v3.2.39 哨兵缩略图优先

## 这次改什么

旧策略是“车机只要在写，所有后台缩略图一律让路”，结果把哨兵的缩略图和飞书封面也一起挡了。v3.2.39 改成按来源分：

- `SentryClips` 的列表缩略图和飞书推送封面：允许在车机写入期间解帧，不再被 `car_active_for_background()` 一刀切。
- `RecentClips`、`SavedClips` 等其它来源：仍保持车机写入让路策略，不抢 U 盘。
- 只解一帧并写缩略图缓存，不碰车机 U 盘数据。

## 推送顺序

`notify_scan()` 现在先检查 `/root/.tesla-live-state.json` 的 `__pending__`：

1. 该事件还有 pending 文件 -> 归档未完成，跳过本轮，不抢跑。
2. 归档完成 -> 按原 20 秒静默门槛确认稳定。
3. 生成哨兵触发帧封面 -> 上传飞书 -> 发卡片。
4. 失败保留 pending，继续按 30 秒到 15 分钟退避重试。
